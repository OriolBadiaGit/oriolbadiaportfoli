2. Quick Start / Setup

Open index.html in a modern browser – it works immediately. For local development:

  1. Place the folder in your web server root (or use Live Server in VS Code).
  2. All paths are relative (images/team/alex.jpeg, 3dfile/Astronaut.glb).
  3. The Three.js background runs as a module – ensure three.module.js and GLTFLoader.js are present.
  4. Sidebar navigation uses single-page section toggling (only one section visible at a time).
<!-- Required Scripts (order matters) -->
<script src="js/jquery.min.js"></script>
<script src="js/bootstrap.min.js"></script>
<script src="js/swiper-bundle.min.js"></script>
<script src="js/simplebar.min.js"></script>
<script src="js/three.module.js"></script>
<script type="importmap">
  {
    "imports": {
      "three": "./js/three.module.js"
    }
  }
</script>
<script type="module" src="js/main.js"></script>

5. CSS Variables – Complete Theme Control

All colors, spacing, and effects are controlled via :root in styles.css:

:root {
    --primary: #6c63ff;           /* Main brand color */
    --primary-dark: #5a52d6;      /* Darker primary */
    --primary-light: #8b84ff;     /* Lighter primary */
    --secondary: #ff44aa;         /* Accent color */
    --dark-bg: #050510;           /* Base dark background */
    --darker-bg: #03030f;         /* Darker background */
    --card-bg: rgba(20, 20, 50, 0.6);   /* Card background with opacity */
    --text-light: #ffffff;        /* Light text */
    --text-muted: rgba(255, 255, 255, 0.7);
    --glass-effect: rgba(5, 5, 20, 0.85);
    --transition: all 0.3s ease;
    --border-radius: 1rem;
    --border-radius-lg: 2rem;
    --sidebar-width: 260px;
}

To create a light version, replace background colors with light values and set text to dark. Change --primary to your brand color for instant rebranding.

6. Three.js 3D Background Configuration

The 3D background includes an animated GLTF model, particle system, and stars. Edit main.js (~line 800 onward):

  • 3D Model Path: Change '../3dfile/Astronaut.glb' to your own GLTF/GLB file.
  • Model Scale & Position: Adjust face.scale.set(2,2,2) and face.position.set(0,-2.2,0).
  • Colors: Modify neonLight1 (cyan), neonLight2 (pink), or star/particle colors.
  • Particle Count: Change particleCount (800) for performance tuning.
  • Camera Movement: Adjust camera.position.x and camera.position.y animation.
// Load your custom 3D model
loader.load('../3dfile/YourModel.glb', function (gltf) {
    face = gltf.scene;
    face.scale.set(2, 2, 2);
    face.position.set(0, -2.2, 0);
    scene.add(face);
});

// Customize particle colors
const particles = new THREE.Points(particleGeo, 
    new THREE.PointsMaterial({ color: 0xff66cc, size: 0.08 })
);
3D Model Not Loading? Ensure the GLTF file path is correct and CORS is not blocking. Check browser console for errors. The model must be in the 3dfile/ folder.

// Replace simulated submission with real API call

9. Single-Page Navigation

The portfolio uses a unique single-section display system:

  • Only one section is visible at a time (Home, About, Skills, Work, Services, Team, Blog, Contact).
  • Sidebar menu links use data-section-id to target the section.
  • Buttons with data-nav-section also trigger section changes.
  • Section switching includes smooth fade-in/up animation.
  • Mobile sidebar toggle appears on screens < 992px.
// Add custom navigation button
<a href="#" data-nav-section="work">View My Work</a>

// To add a new section:
// 1. Add new <section id="new-section" class="horizontal-section">
// 2. Add menu item with data-section-id="new-section"
// 3. CSS will handle the rest

Adding a new section? Copy an existing section structure, give it a unique ID, and add a corresponding menu item in #verticalNavMenu. The navigation system automatically handles the rest.

11. Support & Common Issues

Section not showing? Check that the section has id="section-name" and menu item has data-section-id="section-name". The JavaScript looks for exact matches.
Swiper not working? Ensure swiper-bundle.min.js and swiper-bundle.min.css are loaded before main.js. Check console for errors.
3D model not appearing? Verify the path to Astronaut.glb is correct. The file should be in 3dfile/ folder. Use browser dev tools Network tab to check if the file loads.
Mobile sidebar not toggling? Check that menu-toggle-btn exists and dashboardSidebar ID is correct. The toggle uses CSS class .mobile-open.
